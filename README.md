# Store Inventory Manager

A Python program for managing store inventory by recording product names, prices, and stock quantities.

## Features

- Register initial products
- Add new products
- Search for products by name
- Display all products
- Prevent duplicate product names
- Validate product names, prices, and quantities

## Concepts Practiced

- Functions and return values
- Dictionaries and nested data structures
- Loops and conditional statements
- User input and validation
- Searching and adding records
- Handling duplicate entries
